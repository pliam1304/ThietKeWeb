1. Minh họa 3 phương pháp áp dụng CSS vào trang web

🌐 1. External CSS

Được viết trong tập tin riêng css/style.css và liên kết vào tài liệu qua thẻ <link rel="stylesheet">.

Ưu điểm: Quản lý tập trung, tái sử dụng trên toàn bộ website, trình duyệt có thể lưu bộ nhớ đệm (cache) giúp tăng tốc độ tải trang.

<link rel="stylesheet" href="css/style.css">
Định kiểu bằng <style>

📄 2. Internal / Embedded CSS

Được đặt bên trong cặp thẻ <style> tại phần <head> của tài liệu HTML.

Ưu điểm: Phù hợp cho các định dạng đặc thù duy nhất của một trang web độc lập mà không ảnh hưởng đến các trang khác.

<style>
  .internal-badge {
    background: #10b981;
  }
</style>
Định kiểu trực tiếp style="..."

✏️ 3. Inline CSS

Được áp dụng trực tiếp lên từng phần tử HTML thông qua thuộc tính style.

Đặc điểm: Có mức độ ưu tiên ghi đè cao nhất, nhưng vi phạm nguyên tắc tách biệt giữa cấu trúc và hình thức, khó bảo trì mã nguồn.

<p style="color: #b45309; font-weight: bold;">
  Văn bản dùng inline CSS
</p>

2. Thực nghiệm quy tắc độ ưu tiên (Specificity) và xếp tầng (Cascade)

Thứ tự ưu tiên định kiểu (Từ cao xuống thấp):

  1. Inline CSS: Khai báo qua thuộc tính style (Ưu tiên cao nhất: 1, 0, 0, 0).
  2. ID Selectors: Định danh qua dấu #id (Độ ưu tiên: 0, 1, 0, 0).
  3. Class / Attribute / Pseudo-class: Định danh qua .class, [type], :hover (Độ ưu tiên: 0, 0, 1, 0).
  4. Elements / Pseudo-elements: Định danh qua tên thẻ p, h1, div (Độ ưu tiên: 0, 0, 0, 1).

3. Bảng so sánh 3 phương pháp nhúng CSS (Ứng dụng trong dự án Data Analytics)

Phương pháp Vị trí khai báo Phạm vi tác dụng Độ ưu tiên Tình huống nên sử dụng
External CSS Tập tin .css độc lập liên kết qua thẻ <link> Toàn bộ website (đa trang) Thấp (0, 0, 0, 1 hoặc theo selector) Chuẩn mực công nghiệp, dùng cho toàn bộ hệ thống giao diện, dashboard, báo cáo.
Internal CSS Bên trong cặp thẻ <style> tại <head> Chỉ một trang web hiện hành Tương đương external, ưu tiên theo thứ tự đọc Dùng cho trang đơn (Landing page, trang email marketing, hoặc báo cáo độc lập).
Inline CSS Thuộc tính style="..." trực tiếp trong thẻ HTML Chỉ duy nhất phần tử đó Cao nhất (1, 0, 0, 0) Thử nghiệm nhanh (quick fix), gỡ lỗi, hoặc chèn style động từ JavaScript.
